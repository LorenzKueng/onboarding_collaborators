# Collaborator Onboarding

Setup files and guides for joining a research project as co-author or RA.

**Start here:** [onboarding.md](onboarding.md) — step-by-step setup and daily workflow.

---

## What's in This Repo

| File / Folder | What it is |
|---|---|
| `onboarding.md` | Step-by-step onboarding guide |
| `CLAUDE_global.md` | Template: global Claude Code instructions (edit and symlink) |
| `AGENTS_global.md` | Template: global Codex instructions (edit and symlink) |
| `GEMINI_global.md` | Template: global Gemini CLI instructions (edit and symlink) |
| `claude_settings.json` | Claude Code settings — copy to `~/.claude/settings.json` |
| `codex_config.toml` | Codex settings — copy or symlink to `~/.codex/config.toml` |
| `gemini_settings.json` | Gemini CLI settings — copy or symlink to `~/.gemini/settings.json` |
| `statusline-command.sh` | Powers the Claude Code status bar — copy to `~/.claude/` |
| `skills/` | Reusable AI workflows (link to Claude, Codex, and Gemini skill folders) |
| `documents/` | Reference guides: Claude, Codex, software, project setup. The new-project directory structure is in `documents/Project_setup.md` — your AI builds it on demand (projects live in their own folder, not here) |
